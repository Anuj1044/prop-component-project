## 📌 About The Project

**Job Openings** is a frontend project developed using React.js that displays job opportunities from some of the world's leading technology companies.

The website presents job listings in a clean and organized card-based layout. Each card provides essential information about a job opening, making it easy for users to explore different opportunities.

The main objective of this project was to understand React fundamentals such as **Functional Components, Props, Array of Objects, and Dynamic Rendering using the map() method.**

## ✨ Features

- 🏢 Displays job opportunities from 10 major tech companies.
- 🎨 Clean and minimal card-based UI.
- 🖼️ Company logos displayed on individual job cards.
- 📅 Shows when a job was posted.
- 💼 Displays job titles and experience levels.
- ⏰ Shows employment type (Full Time / Part Time).
- 💰 Displays hourly salary information.
- 📍 Shows job locations.
- 🔖 Save and Apply Now buttons in the UI.
- ♻️ Reusable React components.
- 📦 Dynamic rendering using JavaScript arrays and the `map()` method.
